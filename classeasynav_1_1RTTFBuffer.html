◆ get_tf_info()

TFInfo get_tf_info ( ) const

Returns a snapshot of the current TFInfo.

Returned by value (copy taken while tf_info_mutex_ is held): this is read continuously from both the RT and non-RT threads while set_tf_info() can be called from either during a reconfigure, so a returned reference into tf_info_ would be exposed to a concurrent unsynchronized write (torn/dangling strings).
