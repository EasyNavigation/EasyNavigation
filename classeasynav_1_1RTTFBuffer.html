Detailed Description

Provides functionality for RTTFBuffer.

It also provides the TFInfo with the frames convention used across EasyNav.

Optionally extrapolates into the future: a lookup up to max_future_extrapolation ahead of the latest available transform is answered by integrating the chain's constant twist estimated over the last extrapolation_window. Only runs when tf2 itself fails with a future extrapolation; 50 ms by default, 0 disables it.

◆ get_tf_info()

TFInfo get_tf_info ( ) const

Returns a snapshot of the current TFInfo.

Returned by value (copy taken while tf_info_mutex_ is held): this is read continuously from both the RT and non-RT threads while set_tf_info() can be called from either during a reconfigure, so a returned reference into tf_info_ would be exposed to a concurrent unsynchronized write (torn/dangling strings).
