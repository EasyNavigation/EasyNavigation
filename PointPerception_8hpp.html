Detailed Description

Defines data structures and utilities for representing and processing point-based sensor perceptions.

This header provides:

  • PointPerception: a concrete class for point cloud data.
  • PointPerceptionHandler: a handler for sensor_msgs::msg::LaserScan and sensor_msgs::msg::PointCloud2 messages.
  • PointPerceptionsOpsView: an efficient view-based operator class for processing multiple perceptions (filtering, downsampling, fusion, and collapsing) without duplicating memory.
  • Conversion utilities between ROS messages and PCL point clouds.
