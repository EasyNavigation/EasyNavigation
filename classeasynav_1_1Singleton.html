template<class C>
void removeInstance ( )
static

Destroy the current instance, if any; the next getInstance()/get() call creates a fresh one.

Warning
Only safe to call when no other thread may still be dereferencing a C* obtained from an earlier getInstance()/get() call – that pointer's lifetime is tied to the destroyed instance, and no amount of locking here can protect a caller who is already holding and using it (the lock only serializes this class's own instance_/mutex_ bookkeeping against concurrent getInstance()/ removeInstance() calls). Intended for sequential use, e.g. resetting singleton state between test cases, not for tearing down an instance while it may still be in use elsewhere.
