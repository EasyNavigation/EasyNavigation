Detailed Description

Maps manager that misbehaves on purpose, to test how EasyNav copes with it.

Manages no map (like DummyMapsManager) and, after "<name>.fault_after" updates, injects the fault in "<name>.fault":

  • "none": keeps working.
  • "throw": throws from update().
  • "hang": blocks update() for "<name>.hang_time" seconds on each update.
