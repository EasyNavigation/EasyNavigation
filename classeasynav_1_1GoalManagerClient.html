Detailed Description

Client-side interface for interacting with GoalManager.

Sends navigation goals, handles feedback and result updates, and manages goal lifecycle state.

◆ pause()

void pause ( )

Pause the currently active EasyNav navigation.

This request is not restricted to the current goal owner (e.g. operator tools may pause/resume navigation). EasyNav keeps running its full cycle, but publishes zero velocity until resume is called.
